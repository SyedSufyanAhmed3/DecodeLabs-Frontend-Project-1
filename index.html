About me

I'm a frontend developer in training with a focus on turning designs into fast, readable web pages. I started with plain HTML and CSS because strong fundamentals make every other tool easier to learn.

I enjoy the point where structure, typography and spacing come together. Frontend is the part of a product people actually see, so I try to make it clear, accessible and dependable.

Right now I'm deepening my knowledge of CSS layout, accessibility and version control.
